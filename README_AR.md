# GPS Platform V3 — Updated Notes

هذه النسخة تعيد تصميم المنصة بالكامل وتطبق القواعد التالية:

- User ID ثابت لكل حساب.
- ID شركة رقمي يبدأ من 10001.
- Device ID الحقيقي للإدارة فقط.
- قائمة مركبات + خريطة واحدة.
- الإيقاف المؤقت يحصل تلقائيًا عند انتهاء الاشتراك: الجهاز يبقى ظاهرًا بالرمادي ولا يظهر على الخريطة ولا تتاح خدماته.
- الإيقاف النهائي من الإدارة: الجهاز يختفي كليًا من حساب العميل ولا يظهر له بأي شكل.
- إدارة حسابات كاملة: عرض الحسابات، User ID، الهاتف، عدد الأجهزة، تعديل الاسم/الهاتف/كلمة المرور، إيقاف/تفعيل الحساب.
- إدارة الأجهزة والربط والاشتراك والإيقاف النهائي.
- سجل خدمات السيارات ظاهر للعميل والإدارة مع User ID والحساب والتاريخ والجهاز والنتيجة.
- خدمة السيارة موجودة في واجهة العميل. في هذه النسخة يتم تسجيل الطلب فقط في سجل التدقيق ولا يتم إرسال أمر فعلي للسيارة.
- Geofence كمضلع شفاف خافت: رسم بالنقاط، إغلاق المضلع، تعديل الرؤوس، حفظ/تعطيل/حذف المنطقة.
- تنبيهات دخول/خروج داخل الموقع. SMS يحتاج مزود رسائل خارجي.
- سجل حركة حتى 90 يومًا + تشغيل المسار + نقاط توقف في وضع التاريخ فقط.
- خريطة عادية + صور أقمار صناعية.
- تصميم V3 الأصلي الداكن والفخم والمتجاوب بدون إعادة تصميم.

- polling الخريطة ينشئ marker جديدًا إذا وصلت أول إحداثية بعد فتح الصفحة، بدل انتظار إعادة تحميل الصفحة.

### Render
Start Command الموصى به:
`gunicorn main:app`

main.py يشغل تهيئة/ترقية قاعدة البيانات تلقائيًا عند بدء الخدمة، لذلك لا يلزم تشغيل database.py يدويًا في Start Command لهذه النسخة.

لربط Gateway خارجي مع Render:
- GPS_INGEST_URL = https://YOUR-SERVICE.onrender.com/api/tracker
- GPS_INGEST_TOKEN = قيمة سرية تختارها وتضع نفس القيمة على Render وعلى جهاز الـGateway. لا تشاركها في المحادثة أو داخل GitHub.
- GPS_DB_PATH اختياري إذا استخدمت Persistent Disk لـSQLite. للإنتاج مع عدة عملاء يفضّل PostgreSQL لاحقًا.
