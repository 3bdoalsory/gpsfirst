# GPS Platform V4

هذه النسخة مبنية فوق آخر نسخة نجح معها استقبال جهاز SinoTrack الحقيقي وظهوره على الخريطة.

أهم التعديلات:
- خلفية تسجيل الدخول أصبحت برمجية Responsive (CSS/SVG-like elements) بدون صورة خلفية ثابتة.
- منع Zoom للصفحات مع إبقاء الخرائط قابلة للتكبير.
- منع ظهور صفحات العميل/الإدارة من الكاش بعد تسجيل الخروج.
- دعم Google Maps رسميًا عند وضع GOOGLE_MAPS_API_KEY في متغيرات البيئة.
- مؤشر بطارية شبيه بالهاتف. لا يعرض رقمًا مخمّنًا؛ يظهر "—" حتى تصل قراءة موثقة من الجهاز.
- دعم رسائل LINK وHTBT للبطارية/الأقمار/GSM عندما يرسلها الجهاز.
- V8 يخزن GPS والسرعة والاتجاه وGPS validity وACC من status bit 10 وبيانات الشبكة المؤكدة، ويحفظ الحقول الخلفية غير المعروفة كـ Raw/Unmapped بدون تخمين.
- اسم/نوع المركبة + اللوحة يظهر فوق السهم بشكل خفيف.
- الضغط على السهم يظهر تفاصيل أكبر، وتختفي النافذة تدريجيًا بعد إبعاد المؤشر على الكمبيوتر.
- سجل المسار يحتوي مخطط سرعة/زمن وتلوين للمسار: أخضر/أصفر/أحمر مع انتقالات لونية ناعمة حول الحدود.
- صفحة إدارة أجهزة جديدة: اختيار العميل من Dropdown فقط، كل أجهزته، منتهية الصلاحية، تعديل، وحذف نهائي مع تأكيد.
- الحذف النهائي يمسح الجهاز وGPS والتاريخ والتنبيهات والسجلات والارتباطات حتى لا تختلط مركبة قديمة بجديدة.
- التاريخ والوقت Smart Input: 9/9/2026 -> 09/09/2026، و1430 -> 14:30، و2:30 PM -> 14:30.
- لون الأزرق في صفحة العميل أصبح أخف وأهدأ.
- زر خدمة "إيقاف السيارة" يبقى تسجيل طلب فقط ولا يرسل أمرًا فعليًا للمركبة.

## التشغيل محليًا
```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python database.py
python main.py
```

الدخول الافتراضي:
- admin
- 1234

## Google Maps
ضع في السيرفر:
`GOOGLE_MAPS_API_KEY=<your key>`

بدون المفتاح يبقى زر Google Maps ظاهرًا لكنه معطّل، وتستمر خرائط Leaflet/القمر الصناعي بالعمل.

## ملاحظة قاعدة البيانات
`database.py` يعمل كتهيئة + Upgrade، لذلك عند نقله إلى مشروعك الحالي يمكنه إضافة أعمدة V4 بدون حذف المستخدمين أو الأجهزة أو سجل GPS الحالي.
