# GPS Platform V9.3

Built on the approved V9.2 Command Hotfix baseline.

Changes:
1. Geofence color selector is a clear circular swatch. It updates immediately and applies the same selected color live to the new or edited polygon.
2. History speed chart is taller/wider and easier to read. Speed colors remain exactly: <=40 green, 41-80 orange, 81-120 red, >120 dark red, matching the route.
3. Admin mobile page gets explicit touch vertical scrolling independent of the client dashboard mobile overflow rules.

The V9.2 command/gateway behavior is preserved.
